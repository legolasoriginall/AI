# دستیار دیجیتال (AI)

یک دستیار شخصی فارسی‌زبان که هم **آفلاین** (Ollama) و هم **آنلاین** (Gemini یا هر API سازگار با OpenAI) کار می‌کند؛ می‌تواند فایل بسازد، دستور اجرا کند و اطلاعات را در حافظهٔ محلی نگه دارد.

رابط وب فارسی و راست‌به‌چپ است و کل تاریخچهٔ گفتگوها در SQLite روی همان دستگاه ذخیره می‌شود.

## امکانات

- **دو حالت اجرا:** آفلاین با Ollama، آنلاین با Gemini یا endpoint سازگار با OpenAI؛ انتخاب خودکار در حالت `auto`.
- **ابزارها:** فهرست فایل‌ها، خواندن/نوشتن فایل و اجرای دستور شل — همه داخل پوشهٔ `workspace`.
- **حافظه:** ثبت و بازیابی حقایق (`remember` / `recall`) و تزریق خودکار خاطرات مرتبط به دستور سیستمی.
- **گفتگو با استریم:** پاسخ‌ها به‌صورت SSE می‌آیند و دکمهٔ توقف دارند.
- **چند گفتگو:** ساخت، باز کردن و حذف نشست‌ها از نوار کنار.
- **تنظیمات در رابط:** ارائه‌دهنده، مدل، آدرس Ollama و دستور سیستمی.
- **امنیت:** مسیرها به `workspace` محدود شده‌اند (ضد Path Traversal)، دستورهای خطرناک مسدود می‌شوند و کلیدها فقط از `.env` خوانده می‌شوند.

## اجرا

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env   # اختیاری: کلید یا آدرس مدل را بگذار
python server.py
```

سپس <http://127.0.0.1:3000> را باز کنید.

### حالت آفلاین (Ollama)

```bash
ollama serve
ollama pull llama3.2     # یا هر مدل دیگری
```

اگر Ollama روی همان دستگاه باشد، بدون هیچ کلیدی کار می‌کند؛ در تنظیمات هم می‌توانید مدل را انتخاب کنید.

### حالت آنلاین

در `.env` یکی از این دو را بگذارید:

```env
# هر API سازگار با OpenAI
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_API_KEY=...
ONLINE_MODEL=gpt-4o-mini

# یا Gemini
GEMINI_API_KEY=...
```

نکته: کلیدها را در `.env` نگه دارید؛ این فایل در `.gitignore` است.

### Docker

```bash
docker compose up --build -d
```

## ساختار پروژه

| فایل | نقش |
| --- | --- |
| `server.py` | Flask: صفحهٔ وب، استریم چت (SSE)، نشست‌ها، تنظیمات و فضای کاری |
| `providers.py` | روتر مدل‌ها: Ollama، Gemini، OpenAI-compatible و fallback اختیاری |
| `agent.py` | حلقهٔ عامل: پارس کنش JSON، اجرای ابزار، پاسخ نهایی |
| `tools.py` | ابزارهای فایل/شل/حافظه با محدودسازی و مسدودسازی دستورهای خطرناک |
| `store.py` | SQLite برای نشست‌ها، پیام‌ها و حقایق + تنظیمات |
| `web/` | رابط چت فارسی (HTML/CSS/JS بدون وابستگی) |

## نحوهٔ کار عامل

مدل با یک دستور سیستمی راهنما می‌شود که هرگاه به ابزار نیاز داشت، فقط یک آبجکت JSON برگرداند:

```json
{"tool": "write_file", "args": {"path": "hello.py", "content": "print('سلام')"}}
```

سرور ابزار را اجرا می‌کند، نتیجه را به مدل برمی‌گرداند و این چرخه تا رسیدن به پاسخ نهایی (یا سقف `max_steps`) ادامه دارد.

## محدودیت‌ها

- کیفیت پاسخ به مدل انتخابی وابسته است؛ مدل‌های کوچک محلی ممکن است در تولید JSON درست ضعیف باشند.
- اجرای دستور شل برای دستیار محلی طراحی شده است، نه برای استقرار عمومی روی اینترنت. اگر می‌خواهید در دسترس دیگران باشد، احراز هویت و جداسازی (sandbox) اضافه کنید.
- فیلتر محتوای مدل‌ها در خود مدل است، نه در این برنامه؛ برنامه هیچ بازنویسی روی پاسخ‌ها انجام نمی‌دهد.
- `allow_public_fallback` در تنظیمات به‌صورت پیش‌فرض خاموش است، چون داده را به یک سرویس عمومی می‌فرستد.

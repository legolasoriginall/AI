سه مسیر، یک دستیار

خودتان اجرایش کنید

دموی سایت فقط نمایشی است. هر کدام از این سه مسیر را که انتخاب کنید، در چند دقیقه یک نسخهٔ واقعی و قابل استفاده دارید؛ دستورها را با دکمهٔ «کپی» بردارید. هیچ کلیدی در این صفحه نیست و همه‌چیز روی دستگاه خودتان یا حساب خودتان اجرا می‌شود.

فقط ترمینال؟ راهنمای کامل لینوکس

از نصب Ollama و ساخت venv تا systemd، سرور واسط، تونل HTTPS و عیب‌یابی — همهٔ دستورها برای خط فرمان لینوکس، با دکمهٔ کپی. بخش Flask این راهنما در یک محیط تازه اجرا و تأیید شده است.

راهنمای لینوکس (CLI) ←

مناسب وقتی می‌خواهید مدل روی دستگاه خودتان اجرا شود: بدون کلید API، بدون هزینهٔ سرویس ابری و بدون فرستادن داده به بیرون. پیش‌نیاز: حدود ۴ گیگابایت فضای خالی و دست‌کم ۸ گیگابایت رم.

۱ · نصب Ollama

نصب‌کنندهٔ رسمی را برای سیستم خودتان از ollama.com/download بگیرید (لینوکس هم در همان صفحه دستور نصب دارد). بعد از نصب، در ترمینال این دستور باید شمارهٔ نسخه را نشان دهد:

بررسی نصب
ollama --version

۲ · اجرای سرویس و دریافت مدل

ترمینال
ollama serve
# در ترمینال دوم:
ollama pull llama3.2:3b

مدل‌های پیشنهادی دیگر: llama3.2:1b (سبک‌ترین)، qwen2.5:3b (فارسی بهتر) و qwen2.5:7b (کیفیت بالاتر).

۳ · استفاده در دموی سایت

صفحهٔ سایت HTTPS است و مرورگر اجازهٔ تماس مستقیم با http://127.0.0.1 را نمی‌دهد. اسکریپت تونل، Ollama را با OLLAMA_ORIGINS درست بالا می‌آورد و یک آدرس https://…trycloudflare.com می‌دهد؛ همان را در بخش «مدل‌ها» → «آدرس Ollama» بگذارید.

داخل پوشهٔ پروژه
bash scripts/ollama_tunnel.sh

اگر Ollama را از قبل اجرا کرده‌اید، اول آن را ببندید: OLLAMA_ORIGINS فقط هنگام شروع فرآیند خوانده می‌شود.

مناسب برای اینکه دموی سایت با مدل واقعی کار کند، بدون آنکه کلید API به مرورگر برسد. کلید به‌صورت Secret روی Cloudflare می‌ماند و Worker فقط از دامنهٔ همین سایت (که در ALLOWED_ORIGINS است) پاسخ می‌گیرد.

۱ · حساب و ورود

ترمینال
git clone https://github.com/legolasoriginall/AI.git
cd AI
npx wrangler login

۲ · کلید API به‌صورت Secret

کلید را همین‌جا وارد کنید؛ در فایل ذخیره نمی‌شود
npx wrangler secret put NUMES_API_KEY

۳ · استقرار

یک دستور (ورود، Secret، deploy و تست)
bash scripts/deploy_worker.sh

اگر ترجیح می‌دهید دستی باشد:

دستی
cd worker
npx wrangler deploy

۴ · وصل کردن به دمو

آدرسی مثل https://ai-assistant-proxy.<account>.workers.dev می‌گیرید. در سایت: «اتصال مدل» → «آدرس سرور واسط» → همان آدرس → «تست اتصال». اگر ۴۰۳ گرفتید، دامنهٔ سایت باید در ALLOWED_ORIGINS در worker/wrangler.toml باشد.

کلید Numes را هرگز در فایل، در صفحهٔ سایت یا در چت نگذارید؛ فقط با wrangler secret put.

نسخهٔ کامل با ابزارهای واقعی: ساخت و خواندن فایل، اجرای دستور (داخل پوشهٔ workspace)، حافظهٔ محلی در SQLite و تاریخچهٔ چند گفتگو. همین‌جا می‌توانید Ollama یا هر endpoint سازگار با OpenAI را وصل کنید.

۱ · نصب

Python 3.10+
git clone https://github.com/legolasoriginall/AI.git
cd AI
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

۲ · تنظیمات (اختیاری)

کلیدها فقط در .env می‌مانند
cp .env.example .env
# آفلاین: چیزی لازم نیست؛ Ollama کافی است (بهترین مدل نصب‌شده خودکار انتخاب می‌شود)
# آنلاین رایگان: GEMINI_API_KEY یا GROQ_API_KEY یا OPENROUTER_API_KEY
# ONLINE پولی: OPENAI_BASE_URL + OPENAI_API_KEY + ONLINE_MODEL

۳ · اجرا

سپس http://127.0.0.1:3000
set -a; . ./.env; set +a      # server.py خودش .env را نمی‌خواند
python server.py

بدون خط اول، متغیرهای .env خوانده نمی‌شوند و مدل خالی می‌ماند. جزئیات بیشتر در راهنمای لینوکس.

یا با Docker

همان .env را می‌خواند
docker compose up --build -d

اجرای دستور و ابزارهای فایل برای استفادهٔ شخصی روی دستگاه خودتان طراحی شده‌اند؛ این نسخه را بدون احراز هویت روی اینترنت باز نکنید.

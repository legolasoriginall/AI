راه‌اندازی روی لینوکس — فقط با ترمینال

نسخهٔ کوتاه و قابل‌اشتراک دستورهای README؛ بدون رابط وب و بدون Flask.

نصب

git clone https://github.com/legolasoriginall/AI.git
cd AI
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 cli.py --list-models

قرارداد .env

cli.py خودش .env کنار خودش را می‌خواند؛ نه export لازم است نه python-dotenv. متغیری که در شل export شده باشد بر فایل اولویت دارد. بررسی: python3 scripts/doctor.py.

اجرا

python3 cli.py            # گفتگوی تعاملی با استریم
python3 cli.py -m "سلام"   # یک پیام و خروج
python3 cli.py --json     # NDJSON برای اسکریپت‌ها

داخل چت: /new /models /use NAME /model /remember K=V /tools /status /system FILE /exit

مدل محلی

sudo systemctl enable --now ollama
ollama pull qwen2.5:3b
# .env
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:3b

حالت auto اول مدل محلی را امتحان می‌کند و تا وقتی پاسخ بدهد سراغ سرویس‌های آنلاین نمی‌رود.

نصب Ollama، حالت آنلاین، ابزارها و عیب‌یابی کامل در README مخزن.
